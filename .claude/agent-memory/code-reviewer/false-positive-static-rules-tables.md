Классы вида `*Rules` в `Services/<Domain>/` — статические таблицы чистых функций (без состояния,
без Unity API кроме Vector3/Quaternion/Mathf). Они НАМЕРЕННО не имеют интерфейса и не
регистрируются в `GameLifetimeScope`. Не флагать это как нарушение правила CLAUDE.md
"каждый сервис имеет интерфейс (IXxxService)" и не флагать `static` как нарушение DI.

**Why:** владелец приравнял их к `Mathf` — это не сервисы, а таблицы функций; вынесены из
контроллеров по итогам архитектурного аудита после шага 3 именно ради тестируемости без
Unity-сцены. Рационал зафиксирован в xml-doc самих классов.

**How to apply:** при ревью новых `*Rules`-классов проверять по существу — отсутствие состояния,
отсутствие обращений к Transform/Rigidbody/Animator, наличие EditMode-тестов. Если эти условия
выполнены, `static` без интерфейса — норма. Если в такой класс просачивается состояние или
Unity-компоненты — вот это уже замечание.
